Sou Desenvolvedor Full Stack Web & Mobile, com aproximadamente 2 anos de experiência profissional desenvolvendo e mantendo aplicações em produção, utilizando React, React Native, Expo, Next.js, Node.js, TypeScript, JavaScript e .NET.

Tenho experiência no desenvolvimento de interfaces e funcionalidades, refatoração arquitetural (MVVM), formulários com validação, paginação, scroll infinito, Push Notifications e integração com APIs REST. No desenvolvimento mobile, atuo na geração de builds, publicação nas lojas (Google Play e App Store) e atualização contínua com Expo EAS.

No back-end, desenvolvi APIs REST com Node.js, Express.js, Prisma ORM e PostgreSQL, conduzi migração para Firebase, além de realizar depuração e correção de bugs em aplicações .NET / C# e consultas em bancos SQL Server.
